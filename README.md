## 本地预览

直接用浏览器打开 `index.html` 即可本地预览。
如需本地服务器（解决fetch跨域问题）：

```bash
# Python方式
cd wedding-directory
python -m http.server 3000
# 然后访问 http://localhost:3000

# 或 Node.js方式
npx serve .
```

## 部署到Vercel（推荐）

1. 注册 [vercel.com](https://vercel.com)（可用GitHub登录）
2. 安装Vercel CLI：`npm i -g vercel`
3. 在项目目录下运行：`vercel --prod`
4. 按提示操作，约2分钟部署完成，获得免费域名

**成本：Vercel免费版足够MVP使用，自定义域名约60元/年。**
